# Noise Type Classification Using Time- and Frequency-Domain Audio Features and Machine Learning

## Project Overview
Using Python and machine learning, this study analyzes audio signals from different types of environmental noise to extract various audio features and investigates whether these features can effectively distinguish between different types of noise.

## Method
**Dataset**: ESC-50
**Language**: Python
**Features**: Energy, Zero-Crossing Rate, Spectral Centroid, Spectral Roll-off, MFCCs
**Classifier**: Support Vector Machine (SVM)
**Evaluation**: Accuracy, Precision, Recall, F1-score, and Confusion Matrix
